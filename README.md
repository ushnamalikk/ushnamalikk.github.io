# ushnamalikk.github.io

Personal site. Static HTML; layout and stylesheet derived from the MIT-licensed
[al-folio](https://github.com/alshedivat/al-folio) theme (compiled CSS, recoloured). No build step:
GitHub Pages serves the files as-is (`.nojekyll`).

Pages: `index.html` (About + News), `research.html`, `teaching.html`. CV at `assets/pdf/cv.pdf`.
