# ushna-site

Static personal site. Layout, typography and stylesheet are from the MIT-licensed
[al-folio](https://github.com/alshedivat/al-folio) Jekyll theme (compiled CSS, recoloured);
no build step is needed.

Pages: `index.html` (About + News), `research.html`, `teaching.html`. CV at `assets/pdf/cv.pdf`.

## Deploy to GitHub Pages
Copy the contents of this folder into the `ushnamalikk.github.io` repository (replacing the old
site), commit, and push. The `.nojekyll` file tells GitHub Pages to serve the files as-is.

## Edit
- Theme colour: `assets/css/main.css`, search for `#d6336c` (light) and `#f06595` (dark).
- Headshot: replace `assets/img/headshot.jpg` with a square image (800x800 is plenty).
- News: the table at the bottom of `index.html`.
